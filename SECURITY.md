# Security and data handling

- Do not submit passwords, API keys, `.env` files, private keys, payment
  credentials, or unredacted customer records.
- Scan a copy of the project with secrets and unrelated personal data removed.
- CodeHandoff performs static inspection and does not execute the supplied
  project.
- Reports may still contain file names, code locations, and snippets. Review
  the agreed scope before sharing a repository.
- Use the public service page for initial contact. Do not disclose sensitive
  project material in a public GitHub issue.

For a security concern about this public page, open a private GitHub security
advisory if available rather than publishing exploit details.
